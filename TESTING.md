# Принципы тестирования

- Один тест проверяет один сценарий с понятным риском - по падению видно, какое поведение нарушено
- Проверять наблюдаемый результат. Точные тексты, состав меню и другие детали интерфейса проверять, только если они входят в требование - иначе смена интерфейса ломает тест при рабочей функции
- Выбирать самый дешёвый уровень, который проверяет нужное поведение. E2E использовать для связок, которые важно проверить в браузере
- Для общего механизма достаточно одного показательного случая. Дополнительный случай нужен, если ловит другую поломку
