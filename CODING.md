# Правила написания кода

Только уроки из код-ревью и антипаттерны, без общих практик. Формат: правило - почему (источник). Пример кода - только если без него правило неоднозначно.

## React

- Флаг «отрендерено на клиенте» - через `useSyncExternalStore`, не `useEffect` + `setState`: без лишнего рендера при каждом монтировании (#24).
    ```ts
    const subscribe = () => () => {};
    const useHydrated = () =>
        useSyncExternalStore(
            subscribe,
            () => true,
            () => false,
        );
    ```
- Производное состояние вычислять при рендере, не хранить в `useState` + `useEffect`.
- Данные - через `loader` + TanStack Query (`queryOptions` в `src/lib/*-query.ts`), не `useEffect` + `fetch`.
- TanStack Form: `validators.onSubmit` у полей + `canSubmitWhenInvalid: true`; form-level валидация при существующей ошибке поля не запускается (#57).

## TypeScript

- Фиксированный набор значений - строковый `enum`, без разбросанных литералов; карты по нему - `Record<Enum, T>` (#24).
- Не подавлять ошибки через `any`, `as`, `!`, `eslint-disable` или `@ts-expect-error`. Допустимы `as const`, `satisfies` и приведения типов в моках.

## База данных

- Запросы - через Drizzle builder; `sql` - если builder не умеет. `sql.raw` и склейка SQL с данными запрещены: пользовательские данные в строке SQL создают риск инъекции (#63).

## Тесты

- Чистые функции в `src/lib/*.ts` - с unit-тестами рядом (`*.test.ts`) в том же PR (#41).
- E2E: использовать `gotoHydrated`, чтобы ввод не сбрасывался при гидрации; после редиректа ждать конечный URL (#54).
- **E2E.** Если следующий шаг зависит от записи на сервере, дождаться подтверждения мутации. Иначе проверка может начаться до сохранения (PR №152).

## Вёрстка

- Кнопка и заменяющее её поле - одной высоты и отступов; фокус через ring/outline, чтобы вёрстка не сдвигалась (#45).
- Текст и поля проверять на максимуме из валидатора и слове без пробелов: без выхода за границы, с переносом или обрезкой; при обрезке полный текст в `title` (#45, #64).
- Курсор pointer у кнопок и пунктов меню задан глобально в `styles.css` (Tailwind v4 preflight его убрал) - не добавлять `cursor-pointer` в компоненты (#45).
- Для отключения scroll-snap задавать `scroll-snap-type: none`: снятие `snap-mandatory` оставляет `proximity` (#43).
